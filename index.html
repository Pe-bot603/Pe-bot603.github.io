Página inicial para GitHub Pages com posts em JSON + editor local.

Novo post (local)

Os posts criados aqui ficam salvos no navegador (localStorage).

Como aplicar (GitHub Pages)

  1. Faça push deste branch para o GitHub.
  2. Abra Settings → Pages.
  3. Em Build and deployment, escolha Deploy from a branch.
  4. Selecione branch: main/work e pasta /(root).
  5. Salve e aguarde a URL pública ser publicada.

Dica: se abrir o arquivo direto no computador (file://), os posts padrão ainda aparecem por fallback local.
